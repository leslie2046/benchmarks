# 列表分页

测试计划、运行记录、供应商、供应商内模型及 Dify 配置列表默认每页 10 条，可切换 20 / 50 条，支持前后翻页和页码选择。供应商搜索或类型筛选后回到第一页，模型配置操作仍对应原始模型。删除末页记录后自动回到有效页。列表的计数为当前空间或当前筛选条件的总数，不是当前页条数。

计划和运行记录采用服务端分页，浏览对应页面时每五秒刷新当前页，不跳回第一页。总览和分析的数据窗口不随列表页码变化；旧运行可从历史分页直接打开分析。

测试计划列表在“调度规则”和“下次运行”之间显示“创建时间”，取计划的 `created_at`，按浏览器本地时区展示，悬停可查看完整时间；不会用最近修改时间或下次运行时间替代。

运行记录表保留状态、测试计划、类型、进度、运行时间与操作，不再单独显示场景数或创建时间。“运行时间”取实际开始执行的 `started_at`，按浏览器本地时区显示日期与时间，悬停可查看完整时间；尚未开始或旧记录缺少该字段时显示“—”，不会用创建时间替代。列表的分页排序仍按创建时间降序，不因展示字段变化而改变。

分析看板的“指标数值明细”对当前已加载、筛选后的场景行进行客户端分页，默认每页 10 条，可选 20 / 50 条，支持前后翻页和页码跳转。历史趋势、稳定性和单次运行对比均适用。切换计划、视图、并发档位、指标或对比运行时回到第一页；分页不截断图表数据，不改变曲线和汇总统计。明细分页不会额外获取尚未加载的历史运行。

## API

- `GET /api/plans?page=1&page_size=10`
- `GET /api/runs?page=1&page_size=10`

提供 `page` 时，返回 `{ "items": [], "total": 0, "page": 1, "page_size": 10 }`。页码从 1 开始，`page_size` 为 1–100。超出末页的页码自动收敛到末页；空列表返回第一页。按创建时间降序，ID 降序作为并列排序，避免状态更新导致计划在页面间跳动。总数与当前页在同一数据库快照中读取，遵守当前空间的数据隔离和鉴权。

不提供 `page` 时保持原数组响应及 `limit` 行为，兼容现有调用方（计划默认 100，运行默认 30）。配置列表仍由客户端对已加载的完整配置分页，不截断供测试计划和 Playground 选择的模型。
